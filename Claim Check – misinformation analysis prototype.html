Pipeline

What the prototype runs in your browser is marked live. What a production system would add is marked stubbed here.

  1. IngestAccept pasted text, URLs, or screenshots. Live: pasted text, images (the text is read by AI) and plain-text files. stubbed: URLs and PDFs
  2. Split into claimsSentence segmentation, then classify each as checkable fact, opinion, or prediction. Opinions and forecasts are never given a true/false verdict. Live: rule-based. Production: an LLM claim extractor.
  3. Detect manipulation signalsUrgency, absolute language, unnamed authorities, miracle-cure framing, shouting, missing sources. Live.
  4. Retrieve evidenceMatch each claim against reference material. Live: a built-in reference set of well-documented claims, plus an AI assessment from model knowledge for anything outside it. stubbed: no web search Production: search plus retrieval over fact-check databases, government data and journals, favoring primary sources.
  5. Reason and scoreCombine evidence match and manipulation signals into a verdict and confidence. Confidence reflects evidence quality, not certainty. Live: transparent rules. Production: LLM judgment grounded in cited passages.
  6. ExplainShow the verdict, a confidence meter, the evidence in plain language, red flags, and what would change the assessment.

Verdict rules

VerdictWhen it appliesConfidence rises with
VerifiedReference evidence supports the claimNumber and independence of sources
Partly trueA real element, but exaggerated or missing contextClear mapping to the true part
QuestionableContradicted by evidence, or several manipulation signals with no supportDirect contradiction by strong sources
UnverifiableNo usable evidence either wayStays low by design
Not a factual claimOpinion or predictionNot scored

How the risk score works: each factual claim scores 100 if questionable, 55 if partly true, 40 if unverifiable and 0 if verified. The score is the average, plus 3 points for each warning sign in the wording (maximum 15). Opinions and forecasts are not included. Known limits of this prototype: reference matching is keyword-based and can miss paraphrases, claims outside the reference set get an AI assessment from model knowledge only (capped at medium confidence), and nothing recent can be checked because there is no live search. Treat results as a demonstration of the workflow, not as fact-checking.
